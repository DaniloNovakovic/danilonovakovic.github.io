# Character Package

Use when the mode is `character-package`, or when Danilo asks for the Character
Designer, NPC design, Cicka design, or a character-facing asset brief. Stays
inside Visual Direction Artist unless Danilo asks for a larger character-system
buildout.

## Rules

- **Function first:** every NPC needs one portfolio job, one fast recruiter
  action, and one deeper hiring-manager path.
- **Silhouette first:** primary shape, secondary form or prop, negative-space
  channels, and the smallest mobile size where the character still reads.
- **Presence before lore:** specify `passive`, `aware`, and `reaction` states
  before schedules, dialogue trees, or large animation sheets.
- **Cicka:** autonomous resident (sleepy, curious, grooming, inconveniently
  placed) — not a mascot button.
- **Handoff:** list sprite parts, pivots/origins, baseline, runtime scale, state
  poses, tiny bark family, and open risks before
  `.agents/skills/sketchbook-sprite-pipeline/SKILL.md`.
